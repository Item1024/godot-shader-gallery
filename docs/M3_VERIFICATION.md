# M3 参数与首批 20 项精修验收

日期：2026-10-19。实施前基线：`7ec05bd`。环境：Windows、Godot 4.7.2.stable.official.ed1daf0bf、Forward+ / Vulkan 1.4、NVIDIA GeForce RTX 5060。

## 实现与边界

- `tools/effect_profiles.py` 定义首批 20 项共 76 个专用参数；生成器将中文名称、类型、范围、步长、单位、默认值、必要说明及动画标志写入各项元数据和 catalog。公式仍由 `tools/build_library.py` 维护。
- 面板按元数据建立滑块和键盘数值框、颜色、开关和下拉选择；显示默认值及单位，参数过多时纵向滚动。“播放”区单独控制播放器；静态项不显示速度。其余 401 项保留“基础参数”和原有绑定，零搜索结果清空旧预览。
- 重置显式恢复每个材质的元数据默认值、时间 0、速度 1、启用状态，并清除事件。类型、范围、选项及 uniform 存在性会在绑定时检查，不依赖控件信号完成重置。
- 高斯在图库和原 demo 中使用“原图 → 横向 → BackBufferCopy → 纵向”，两个材质同步参数和开关。质量为每方向 5 / 9 / 13 次取色，权重分别归一化。
- 新增 `assets/neutral_lut.png`：标准库 PNG 写出器生成 256×16 RGB 图，16 个蓝色切片横排；红、绿、蓝格点分别为 `(x % 16) × 17`、`y × 17`、`(x // 16) × 17`。与已有暖色表都作为原始 RGB 数据读取，不加 `source_color` 颜色转换；红绿在片内双线性采样，蓝色在相邻两片插值，最高片钳制为 15。
- 水面波高表示幅度上界，CPU 与 Shader 使用同一波长和波形。最大波高下先定位有限波面内最近的变号段，再进行最多 8 次有界 Newton 修正；这修复了原初值在陡波时失收敛的问题。保留 M2 的 4 界面像素拖动阈值和点击释放触发规则。
- 只修改首批公式及必要共享逻辑；421 个目录和编号、原有实现标签及 59 项“演示近似”保持。M1 图片、报告和源码哈希均未改。材质预设、`usage.tscn` 与空工程复制验证属于下一步 M4。

## 失败、未验证和已知限制

- 最终必要检查失败数为 0。实施中曾发现无光照材质的发光输出无效、陡波命中失收敛、空搜索的数组类型异常；均修复后重跑。数值框会有浮点舍入，控件默认值使用 `1e-9` 容差；材质默认及固定状态像素复现仍严格比较。
- 全库退出仍报告 `7 RIDs of type "Texture" were leaked`。来源尚未定位，资源释放没有验收通过；没有以运行通过掩盖该警告。
- 401 项只完成运行回归及基础参数路径保留，没有逐项视觉精修。全库 audit 的 PASS 仅表示运行检查通过。
- 水面求交限于有限解析波面；GPU 用细分三角形逼近。护盾限于本例球面，事件采用最新一次替换旧事件。全息为表面条纹，玻璃只能采样已画出的不透明背景，不是完整物理实现。
- 高斯大半径低质量仍可能呈现稀疏采样，未承诺画质或性能等同于无限核。LUT 为 16³ 插值，非无限精度颜色变换。
- 未验证其他显卡、系统、Mobile / Compatibility / Web；未交付 M4 复制接入资产，未建立 M5 的 140 状态人工确认参考图，未做 M6 性能预算或按需刷新。
